# Centralized Log Management System

## Project Overview
A centralized Linux log management
system using the ELK Stack.

## Technologies
- Ubuntu Linux
- Docker
- Elasticsearch
- Logstash
- Kibana
- Filebeat

## Features
- Centralized Log Collection
- Log Analysis
- System Error Monitoring
- Security Log Monitoring
- Dashboard Visualization

## Architecture
Ubuntu Servers
     |
  Filebeat
     |
  Logstash
     |
Elasticsearch
     |
   Kibana

## Installation
Docker Desktop with WSL2 integration
is required.
